# Java Training Plan

This repository tracks Hung Nguyen Huu’s Java training roadmap.

## Session 1: Java Fundamentals

- Folder: [`fundamental/`](./fundamental/)
- Timeline: 15 working days
- Stack: Java JDK 21, IntelliJ IDEA Community Edition
- Reference: *Head First Java, 3rd Edition*

### Scope

- Java basics: JVM, syntax, branching, loops
- OOP fundamentals: classes, objects, encapsulation, methods
- Core language: primitives, references, memory, garbage collection
- Intermediate topics: APIs, collections, generics, lambdas, streams, exceptions
- Practice topics: GUI, file I/O, networking, threads, concurrency

## Session 2: RESTful Web Services with Spring

- Folder: [`spring-framework/`](./spring-framework/)
- Timeline: 28 working days
- Stack: Java 21, Spring Boot 3.x, Spring Framework 6, Spring Security 6, Spring Data JPA
- Reference: *Mastering RESTful Web Services with Java*

### Scope

- Spring core: DI, IoC, bean lifecycle, AOT
- REST APIs: controllers, request mapping, JSON, error handling, HTTP clients
- Persistence: entities, repositories, transactions, queries
- Security: JWT, roles, OAuth 2.1, password encoding
- Testing: JUnit 5, MockMvc/WebTestClient, test slices
- Production: Actuator, observability, containerization, Virtual Threads

### Practice Project

Build a task management REST API with:

- user registration and login
- JWT-protected task CRUD
- role-based access
- consistent JSON responses
- RFC 7807 error handling
- unit and integration tests
- containerized deployment

### Advanced Topics

- JWT role validation when roles change
- SQL tuning, indexes, and large-scale data loading
- database migration and seeding
- API versioning
- unique constraints
- OAuth2 Resource Server handling
- multipart upload for avatar updates
- Docker Compose
